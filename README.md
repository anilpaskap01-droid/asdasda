# Benimle barışırsan mutlu olurum ♡

HTML, CSS ve JavaScript ile hazırlanmış, mobil uyumlu küçük bir barışma sitesi.

- **Barış:** Mutlu bir mesaj ve konfeti gösterir.
- **Barışma:** Anlayışlı bir mesaj gösterir.
- **Baştan bak:** İlk ekrana döner.
- Klavyeyle kullanılabilir ve azaltılmış hareket tercihini destekler.
- Seçimler kaydedilmez veya herhangi bir sunucuya gönderilmez.

## Açmak

`index.html` dosyasını tarayıcıda açabilirsin. Kurulum, paket veya sunucu gerekmez.

## Render ayarları

Render'da **New → Static Site** seç ve bu GitHub reposunu bağla:

| Ayar | Değer |
| --- | --- |
| Branch | `main` |
| Root Directory | Boş bırak |
| Build Command | `echo ready` |
| Publish Directory | `.` |

**Start Command gerekmez.** Start Command alanı görüyorsan Web Service yerine Static Site oluştur.

Bu repo yalnızca kaynak kodunu içerir; Render'da yayınlamak için yukarıdaki ayarlarla dağıtımı başlatabilirsin.
